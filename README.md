# Song Splash 🎵

**ทายผิด ตกน้ำ!**

เกมทายชื่อเพลงแบบเรียลไทม์ ผู้เล่นฟังเพลงจาก YouTube แล้วเดินไปยืนในหลุมที่ชื่อเพลงถูก ใครยืนผิดหลุมจะตกน้ำ

- `server/` Bun + WebSocket (เกมทั้งหมดรันฝั่ง server ผู้เล่นโกงตำแหน่งไม่ได้)
- `client/` Vue 3 + Vite (หน้าเล่น `/` และหลังบ้าน `/admin`)
- `shared/protocol.ts` type และ layout ของหลุมที่ทั้งสองฝั่งใช้ร่วมกัน

## รันเลย (มี build มาให้แล้ว)

```bash
cd server
ADMIN_KEY=รหัสลับ bun src/index.ts
```

- ผู้เล่น: http://localhost:3000
- หลังบ้าน: http://localhost:3000/admin

## พัฒนาต่อ

```bash
bun install            # ที่ root ติดตั้งทั้ง client และ server (workspaces)
ADMIN_KEY=รหัสลับ bun run dev   # server :3000 + vite :5173 (proxy /ws ไปที่ server)
```

เปิด http://localhost:5173 ได้เลย และมือถือในวงเดียวกันเข้าผ่าน IP เครื่องได้ (vite เปิด host ไว้แล้ว)

build ใหม่หลังแก้ client: `bun run build` แล้ว `bun run start`

## ตั้งค่า (env)

| ตัวแปร | ค่าเริ่มต้น | ใช้ทำอะไร |
|---|---|---|
| `ADMIN_KEY` | `changeme` | รหัสเข้าหลังบ้าน |
| `PORT` | `3000` | พอร์ต |
| `DATA_FILE` | `server/data/questions.json` | ไฟล์เก็บคำถาม |
| `CLIENT_DIST` | `client/dist` | โฟลเดอร์ไฟล์หน้าเว็บที่ build แล้ว |

ค่ากติกาอื่นอยู่ที่ต้นไฟล์ `server/src/index.ts` (ความเร็วเดิน, ระยะห่างตัวละคร) และ `shared/protocol.ts` (เวลานับถอยหลัง, เวลาโชว์เฉลย, การวางหลุม)

## Docker

```bash
docker build -t song-splash .
docker run -p 3000:3000 -e ADMIN_KEY=รหัสลับ -v $(pwd)/data:/app/server/data song-splash
```

state ของเกมอยู่ใน memory ให้รันแค่ 1 replica (ถ้าจะ scale ต้องแยกห้อง/ย้าย state ออกไปก่อน)

## กติกาที่ตั้งไว้

- ทุกข้อเริ่มด้วยนับถอยหลัง 3 วิ ให้อ่านป้าย แล้วเพลงเล่นตามเวลาที่ตั้งในหลังบ้าน
- หมดเวลา ใครไม่ได้ยืนในหลุมที่ถูก (ติ๊กถูกได้มากกว่า 1 หลุม) ตกน้ำ
- คะแนนแบบ Kahoot: ตอบถูกได้ 500–1000 ตามความเร็ว (นับจากเวลาที่เดินเข้าหลุมสุดท้าย ย้ายหลุม = เริ่มนับใหม่) + โบนัสสตรีค 100 ต่อข้อที่ถูกติดกัน สูงสุด 500
- แอดมินเลือกโหมดก่อนกดเริ่ม
  - **เอาตัวรอด**: ผิดแล้วตกรอบ ถ้าผิดกันหมดทุกคนรอบนั้นรอดหมด จบเมื่อเหลือคนรอดคนเดียวหรือหมดคำถาม ถ้ารอดหลายคน คะแนนสูงสุดชนะ
  - **สะสมคะแนน**: ผิดแล้วตกน้ำแต่ข้อต่อไปกลับมาเล่นได้ เล่นครบทุกข้อ คะแนนรวมสูงสุดชนะ เข้ากลางเกมก็เล่นได้ทันที
- เน็ตหลุดแล้วกลับเข้ามาภายใน 15 วิ ตัวละครยังอยู่ (จำผู้เล่นด้วย id ใน localStorage)
- โหมดเอาตัวรอด: เข้ากลางเกมจะได้ดูอย่างเดียวจนเริ่มรอบใหม่

## ข้อควรรู้เรื่อง YouTube

- iOS Safari ไม่ให้เล่นเสียงอัตโนมัติ ถ้าเพลงไม่ดังจะมีปุ่ม "แตะเพื่อเปิดเสียง" ขึ้นบนแผ่นเสียง
- คลิปบางตัวปิดการ embed ใช้ปุ่ม "ทดลองฟัง" ในหลังบ้านเช็กก่อนได้
- ตัวเกมเบลอวิดีโอไว้ตอนทาย ถ้าจะใช้งานเชิงพาณิชย์ ควรเช็ก YouTube API Terms เรื่องการซ่อน/บังผู้เล่นก่อน
